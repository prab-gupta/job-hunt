Sobre o trabalho AI Engineer

Its time to burst the bubble, and we will do it together!

What You'll do:

- Designing, building, and maintaining AI/LLM services and APIs in Python (Django, FastAPI/Uvicorn), backed by PostgreSQL, Redis and Celery, containerised with Docker and delivered through GitLab CI;

- Implementing retrieval-augmented generation (RAG) pipelines end to end: chunking, embeddings, hybrid retrieval, reranking and vector database integration;

- Designing agents and tools with orchestration frameworks (Google ADK, Haystack, LangGraph), including Model Context Protocol (MCP) tool calling, agent/tool policies and versioned, composable system prompts stored in the database;

- Ensuring LLMOps quality: Langfuse tracing, evaluation sets and LLM-as-judge methods, token and cost controls, latency reduction, and streaming performance;

- Writing clean, tested, and documented code (OpenAPI, pytest, database migrations, uv, ruff), taking part in code reviews and handing over knowledge to the permanent team before the end of the assignment;

- Full remote, based in Portugal;﻿


Who You Are:

- Strong proficiency in Python and its backend ecosystem (Django, FastAPI), including PostgreSQL, Redis, Celery and Docker.

- Proven hands-on experience building production RAG systems and working with vector search, embeddings and reranking.

- Practical experience with agent orchestration frameworks (Google ADK, Haystack or LangGraph), prompt engineering and MCP-based tool calling.

- Solid understanding of LLMOps: tracing and observability (Langfuse), evaluation methodologies, and managing cost, latency, and streaming.

- Engineering discipline: API design with OpenAPI, automated testing with pytest, database migrations, CI/CD with GitLab and modern Python tooling (uv, ruff).

- Fluent in portuguese and english; ﻿
