When making CVs and motivation letters, prevent context rot. **Why:** Stale information from prior applications can bleed into new ones - wrong company names, outdated role details, claims that applied to a different posting. **How to apply:** Before generating any CV or cover letter, re-read the specific job posting fresh. Never reuse motivation letter text without verifying every claim still applies to THIS role. Check that headline/summary/skills edits match the current target, not a prior one. Cross-check company name, role title, and requirements against the actual posting before finalizing. Related: [[feedback_no_coauthor]], [[feedback_session_defaults]]
