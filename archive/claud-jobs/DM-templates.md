# Outreach DM templates (3)

Rules of thumb: keep to 3-5 sentences, one specific hook about THEM, one concrete proof from you, one soft ask. Never open with "I'm passionate about". Lead with agents + shipped code, never no-code. Demo link: github.com/prab-gupta/llm-doc-parser. For Venice/Italy targets you can add "happy to meet in person".

Placeholders in [brackets] — fill before sending.

## 1. Founder cold DM (early-stage AI / flex-office / agent company)
Use for: founders on the Connect Tracker + AI Agent Cos tabs where no warm link exists.

> Hi [First name], I've been following [Company] — [one specific, accurate line about their product, e.g. "your on-demand workspace booking flow" or "your agent that does X"]. I'm an applied-AI engineer who ships production agents and the integration plumbing around them: at FlowSpace I built an LLM listing agent that onboarded 20+ operators and ran the OfficeRnD/Nexudus API integrations, and I led the migration onto a Next.js + Laravel stack. It looks a lot like the forward-deployed / solutions work [Company] needs as you scale. Worth a 15-minute chat, or should I send a short note to whoever owns that? A sample of how I build: github.com/prab-gupta/llm-doc-parser.

Shorter variant (LinkedIn connect note, <300 chars):
> Hi [First name] — applied-AI engineer here (ship production LLM agents + API integrations; built FlowSpace's listing bot and OfficeRnD/Nexudus integrations). [Company]'s [product] is squarely the FDE/solutions work I do. Open to a quick chat?
