## Upload method note (technical)
The Browser pane's strict same-origin CSP on jobs.ashbyhq.com (connect-src 'self' plus an explicit allowlist, default-src 'none') blocks any fetch/XHR to a local file server, so the network-fetch shortcut for attaching files does not work on this ATS. Both PDFs were rebuilt entirely client-side: base64 of each file was assembled in the page's own JS context in 2,000-character chunks (with a length check after every append), decoded to bytes with atob(), and verified against the source files' real SHA-256 hashes via crypto.subtle.digest before building File objects and attaching them through DataTransfer. One transcription error was caught this way (a single 2,000-char segment did not match its expected hash) and was corrected before upload; both final hashes matched the source files exactly (CV f8b48f50bd74eca43a9eac36c21481ee5cfd91e5def2baa9c9a4557e69f05761, cover letter 4dc0eb34c61bb2289329e81f66e573c1c676e99ca42d519e3ff5e7cab0489d98).
