## Key strategic findings

### What works
- **Ashby board APIs** (api.ashbyhq.com/posting-api/job-board/<company>) for bulk verification
- **Free keyless job APIs**: Remotive, Jobicy, Arbeitnow (293 jobs in one shot)
- **Personio XML** endpoint for pre-filtering on years/seniority
- **Recruitee API** for checking CV-only status without browser
- **justjoin.it** was highest-yield channel until reCAPTCHA gate appeared
- **Company-direct ATS boards** over aggregator searches

### What's dead
- LinkedIn (all reposter accounts), remotive (collapsed to 16 jobs), europeremotely.com (parked), WTTJ/Otta (SPA shells), nowhiteboard.org (404), jobspresso/dynamitejobs/justremote (SPA shells)
- Workable location param (geocodes "Remote" to Oregon)
- n8n's own job board (excludes Italy)

### Blockers ranked by kill count
1. **Language** (Polish, German, Italian native, French, Ukrainian)
2. **Per-country geo-fencing** (Italy absent from most EU lists)
3. **Seniority** (5+ years, 8+ years)
4. **Degree requirements** (MSc, CS degree with no equivalence clause)
5. **CAPTCHAs** (reCAPTCHA, hCaptcha, Cloudflare Turnstile)

### ATS traps documented
- Ashby: React-state wipe on error re-render, "possible spam" flag, location fields vary by tenant
- Workable: resume input unreachable by clicking, CV parse wipes address, Turnstile per-tenant
- Greenhouse: silent board-index serve for dead roles, fields required without markup
- Traffit: Country/City custom dropdowns with empty proxy selects
- Personio: DACH-dominated tenant base
- Recruitee: custom radios select wrong option when hidden input clicked, hCaptcha
- Lever: Google-places autocomplete clears on re-render, hCaptcha
- Bending Spoons: email-code verification as final step
