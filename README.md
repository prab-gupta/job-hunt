# Prabhavit's job search

Private working archive and portable handoff for the job search. Snapshot: 18 September 2026.

**Start with [START_HERE.md](START_HERE.md).** An agent should need the four short handoff documents, then only the evidence relevant to its next action.

| Read | Purpose |
|---|---|
| [Start here](START_HERE.md) | Read order, resume prompt, source precedence |
| [Profile](handoff/PROFILE.md) | Confirmed facts and claim limits |
| [Workflow](handoff/WORKFLOW.md) | Search, apply, outreach and evidence rules |
| [Current state](handoff/STATE.md) | Snapshot, unfinished work, next actions |
| [Open queue](handoff/open-queue.csv) | Open items copied from the original queue |
| [Full job workspace](archive/claud-jobs/) | CVs, letters, tools, trackers, confirmations, interview prep and run logs |
| [Claude history](history/claude/index.json) | Job-related user/assistant conversation exports |
| [Sources and limitations](handoff/SOURCES.md) | Provenance, conflicts and omitted runtime data |

The original working folder remains intact. The archive is a snapshot, not a live sync. No scheduler or browser session starts by cloning this repository. This repository contains personal job-search and email records: keep it private.
