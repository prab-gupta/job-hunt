## 9. ATS quirks worth remembering

- **Ashby + automated browser: the first submit can be rejected with "Your application submission was flagged as possible spam."** The message itself invites a resubmit; retrying once cleared it. Never attempt a fingerprint or detection workaround.
- **Ashby error re-renders silently empty fields in React state while the DOM still shows the values** (hit on Zapier: Preferred First/Last + Email). The form looks complete and fails validation anyway. After any failed submit, clear via the native value setter and retype with real keystrokes, then re-verify every field before resubmitting.
- Ashby location widgets are often **country-level only** - "Venice" returns "No results", "Italy" works. Do not assume city granularity.
- Greenhouse / MyGreenhouse often autofills a STALE `Prabhavit_CV-.pdf`; remove it and re-upload the canonical `Prabhavit_CV.pdf`.
- Lever: the "Current location" field is a Google-places autocomplete that clears unless you select a suggestion from the dropdown (use "Venice, ITA").
- Ashby: `form_input` is unreliable; use direct clicks / keystrokes. Some links return "Job not found".
- Teamtailor: decline non-essential cookies; the phone widget defaults to the wrong country.
- **Workable now shows a CLOUDFLARE TURNSTILE on some tenants** (Flosum and GoReel had it, SAP Fioneer did not, so it is per-tenant). The submit button hangs on "Submitting..." with NO error text, which in the DOM is indistinguishable from a silent failure. ALWAYS screenshot before concluding anything. It is a CAPTCHA: fill everything, then hand back for one tick.
- reCAPTCHA "I'm not a robot" is a hard stop; never solve it, always hand back. (Invisible reCAPTCHA that passes on its own is fine.)
- Closed dropdowns that exclude his true answer (US-states-only residence, Poland-only domicile, German-proficiency with no "None") = hand back, never invent.
- Demographic sections are almost always explicitly voluntary - leave them entirely blank rather than guessing.
- **justjoin guest-apply now raises a visible reCAPTCHA on submit.** It did not on 13 Aug, when five justjoin applications went through cleanly. Assume every justjoin role is a hand-back unless he drives the browser himself. This matters: justjoin was the most productive single vein in the search.
- **The Workable "remote ... in Italy" listing pages are dominated by Patrique Mercier / Mercier Consultancy / Volga Partners** - Italian-native BPO and language-annotation work, usually with relocation to Greece or Bulgaria. Skip that whole channel.
- Workable's own apply form re-parses the uploaded CV and can **wipe city/country after upload** - refill address fields after attaching the resume, and its radio groups regenerate their element ids on every click, so mark-and-click one question at a time.
- Personio forms hide the real file input; click the visible "Add file" button to open the chooser. The submit button stays disabled until the CV is attached, which is a useful readiness signal.
- **n8n's remote-Europe country list excludes Italy**, so every n8n req is ineligible for him regardless of fit. Do not re-check.
